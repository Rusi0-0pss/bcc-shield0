# BCC Shield

Прототип ИИ-защиты клиентов Банка ЦентрКредит от мошенников (ITU Hackathon).

**Сайт:** https://rusi0-0pss.github.io/bcc-shield0/

- Клиентская часть в стиле приложения bcc.kz: рейтинг доверия, проверка каждого перевода ИИ, защита близких, апелляции.
- Ситуации: звонок «сына» с дипфейк-голосом (Voice Guard), дропперство, «служба безопасности банка», фишинг, фейковые инвестиции.
- Страница разработчика: 3D-карта городов Казахстана, живой поток транзакций с ускорением 1×/2×/4×, аналитика, настройка модели.
- Режим презентации на 7 шагов.

Все данные синтетические. Стек: HTML, CSS, JavaScript, Three.js, Web Speech API, Web Audio API, PWA.
